# Jiahua Wu — Academic Website

Source repository for [wu-jiahua.github.io](https://wu-jiahua.github.io), built with Jekyll and styled after [html-slide](https://github.com/Yanwei-Sun/html-slide).

## Structure

- `_pages/about.md` — Homepage biography, selected research, and student note (`/`)
- `_pages/research.md` & `_data/research.yml` — Working papers and publications (`/research/`)
- `assets/pdf/Jiahua_Wu_CV.pdf` — Curriculum Vitae (`/cv/`)
- `assets/pdf/papers/` — Paper PDFs
- `slides/` — Self-contained HTML presentation decks
- `_sass/_html_slide.scss` — Typography, palette, and layout styles

## Local Preview

```bash
bundle exec jekyll serve
```
